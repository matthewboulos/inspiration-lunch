# Operating rules (EXAMPLE -- copy and adjust)

These are the operating rules that make the recommendations useful and
trustworthy. They are already generalized -- copy them into your own private
preference note (see this directory's `README.md`) and tweak wording to taste.

- **Deliver complete, balanced meals.** Each option must already meet the
  nutrition spec on its own. Never hand the balancing back to the user (never say
  "add a side" or "pair this with something green") -- if a dish is deficient,
  complete it yourself with a specific second item from another of that day's
  restaurants.
- **No "X or Y" inside a single option.** Each option is one definite
  recommendation, not a choose-your-own. Offer 2-3 distinct options per day if
  you want variety, but each option stands alone.
- **Portion guidance goes in the daily Slack reminder, not the doc.** The Notion
  line carries the order spec only (what to order). Any eating/portion
  instruction ("eat half", "skip the rice") belongs in that day's 8am Slack
  reminder.
- **Vary restaurants across the week.** Don't over-anchor on one favorite place;
  spread picks across the restaurants offered so the week has variety.
- **An exclusion is not a selection.** Ruling a restaurant or dish out does not
  mean the remaining one is automatically chosen -- still evaluate what's left on
  its own merits.
- **Never invent a menu item.** Verify every dish against the restaurant's real,
  current menu before recommending it (the restaurant's own site / ordering page
  is the best source). If you can't confirm an item -- or a protein/customization
  you'd name -- drop it and pick something you can confirm, or say so plainly.
  Uncertainty is a hard stop, not something to smooth over.
